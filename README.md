## 🧭 Focus

- **AI Agent 工具链**：Agent 工作区管理、Skill 生成与校验，让 AI 编程 Agent 用起来更顺手
- **知识管理**：给 Obsidian 做统一工作台，多 vault 集中管理，数据完全本地隔离
- **学术写作流水线**：离线 AI 论文写作工作台，阶段化流水线 + 多级质量门，AI 只出草稿、人做决策
- **Local-First 优先**：所有核心工具离线可用、数据不出本机，全程可审计
